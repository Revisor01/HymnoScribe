# Requirements: HymnoScribe

**Defined:** 2026-04-07
**Core Value:** Ein Liedblatt zusammenstellen und sofort sehen, wie es gedruckt aussieht — ohne Trial-and-Error.

## v1 Requirements

### Security

- [ ] **SEC-01**: Rate Limiting auf Login-, Password-Reset- und Verification-Endpoints (5 Versuche/15min pro IP)
- [ ] **SEC-02**: SQL-Injection in DDL-Statements gefixt (Whitelist-Validierung für Tabellennamen)
- [ ] **SEC-03**: Credential-Logging beim Server-Start entfernt, DB-Passwort rotiert
- [ ] **SEC-04**: CORS-Wildcard-Fallback entfernt, nur explizite Origins erlaubt
- [ ] **SEC-05**: TLS-Validierung für E-Mail-Transport aktiviert (rejectUnauthorized: true)
- [ ] **SEC-06**: Passwort-Validierungsregeln (Mindestlänge 8 Zeichen, Komplexitätsregeln)
- [ ] **SEC-07**: Helmet Security Headers aktiviert
- [ ] **SEC-08**: Input-Validierung mit express-validator auf allen API-Endpoints

### Backend-Struktur

- [ ] **BACK-01**: server.js modularisiert in Routes, Controller, Middleware, Services
- [ ] **BACK-02**: Middleware-Reihenfolge dokumentiert und durch Modularisierung erhalten

### Layout Engine

- [ ] **LYOT-01**: Einheitliche Layout-Engine in pt als kanonischer Einheit erstellt
- [ ] **LYOT-02**: DOM-Renderer rendert Layout-Engine-Output als WYSIWYG-Vorschau
- [ ] **LYOT-03**: PDF-Renderer rendert Layout-Engine-Output als pdf-lib PDF
- [ ] **LYOT-04**: Vorschau und PDF-Export sind pixelgenau identisch (1:1 WYSIWYG)
- [ ] **LYOT-05**: Divergierende Konstanten zusammengeführt in einer constants.js
- [ ] **LYOT-06**: window.lastCalculatedBreakPositions-Kopplung eliminiert

### WYSIWYG Controls

- [ ] **WYSI-01**: Bildgrößen frei einstellbar per Drag-Handle (nicht immer volle Seitenbreite)
- [ ] **WYSI-02**: Spacing-Drag-Regler: Abstände zwischen Objekten live per Ziehen anpassbar
- [ ] **WYSI-03**: Freie Schriftgrößenwahl über H1/H2/H3 hinaus
- [ ] **WYSI-04**: Format-Live-Switch: Wechsel zwischen A5/A4/A3/DIN-Lang mit sofortigem Re-Layout
- [ ] **WYSI-05**: Manuelle Seitenumbrüche setzbar und in Vorschau sichtbar

### Element-Management

- [ ] **ELEM-01**: Refrain kann als erstes Element eines Liedes gesetzt werden
- [ ] **ELEM-02**: Flexible Reihenfolge aller Elemente innerhalb eines Liedes (Strophen, Refrain, etc.)
- [ ] **ELEM-03**: Umbrüche innerhalb von Strophen/Elementen möglich (Fortsetzung auf nächster Seite)

## v2 Requirements

### Extended Features

- **EXT-01**: Undo/Redo für Layout-Änderungen
- **EXT-02**: Vorlagen-Bibliothek mit vordefinierten Liedblatt-Designs
- **EXT-03**: Batch-Export mehrerer Liedblätter
- **EXT-04**: Audit-Logging für DSGVO-Compliance

## Out of Scope

| Feature | Reason |
|---------|--------|
| Freie Positionierung von Elementen | Bricht Seitenumbruch-Logik, widerspricht einfacher Bedienung |
| Inline-Editing im Preview | Fragile Daten-Synchronisation, hohe Komplexität |
| Tiefer Undo/Redo-Stack | Komplexität/Nutzen-Verhältnis zu hoch für v1 |
| OAuth/Social Login | E-Mail/Passwort reicht, Aufwand lohnt nicht |
| Mobile App | Web-first, responsive reicht |
| Echtzeit-Kollaboration | Einzelnutzer-Editing reicht |
| Automatische Lied-Datenbank | Jede Institution baut eigene Bibliothek (Copyright) |
