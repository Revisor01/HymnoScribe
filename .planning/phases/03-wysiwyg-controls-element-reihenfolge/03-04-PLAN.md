**saveSessionToLocalStorage() — Neues Format**: Den `localStorage.setItem`-Aufruf (Zeile 195) von Plain-Array auf Wrapper-Objekt umstellen:

```javascript
// ALT:
localStorage.setItem('lastSession', newDataString);

// NEU: Wrapper mit overrides
const sessionPayload = {
    version: 1,          // Migration-Guard für spätere Format-Änderungen
    items: sessionData,  // bisheriges Array
    overrides: serializeOverrides()
};
const payloadString = JSON.stringify(sessionPayload);
localStorage.setItem('lastSession', payloadString);
lastSavedData = payloadString; // auch lastSavedData aktualisieren (war newDataString)
```

Hinweis: `lastSavedData` (Zeile 189) wird für Change-Detection genutzt. Die Prüfung `if (lastSavedData === newDataString)` muss VORHER mit `newDataString` (items-only) bleiben, um unnötige Serialisierungen zu vermeiden. Nach der Prüfung erst den Payload mit overrides bauen.

**loadLastSession() — Backward-Compat**: (Zeile 210-220) auf neues Format umstellen:

```javascript
export function loadLastSession() {
    const lastSession = localStorage.getItem('lastSession');
    if (lastSession) {
        try {
            const raw = JSON.parse(lastSession);
            // Backward-Compat: altes Format war ein Array
            if (Array.isArray(raw)) {
                applySessionData(raw);
                clearOverrides(); // altes Format hatte keine Overrides
            } else if (raw && raw.version === 1) {
                // Neues Format
                if (raw.overrides) {
                    deserializeOverrides(raw.overrides);
                }
                applySessionData(raw.items || []);
            }
        } catch (error) {
            console.error('Fehler beim Laden der letzten Session:', error);
        }
    }
}
```

**loadSession(id) — Backend-API**: (Zeile 62ff) `applySessionData` anpassen — muss neues Format verstehen:

```javascript
export async function loadSession(id) {
    // ...
    const session = await response.json(); // session.data ist das gespeicherte Objekt
    const raw = session.data;
    if (Array.isArray(raw)) {
        // Altes Format
        clearOverrides();
        applySessionData(raw);
    } else if (raw && raw.version === 1) {
        if (raw.overrides) deserializeOverrides(raw.overrides);
        applySessionData(raw.items || []);
    } else {
        // Unbekanntes Format — sicher fallback
        clearOverrides();
        applySessionData(Array.isArray(raw) ? raw : []);
    }
}
```

Ebenso `loadVorlage(id)` (Zeile 333): gleiche Logik für `vorlage.data`.
