  <action>
    **Fix A: TLS-Validierung (SEC-05)**

    In der `createTransporter()`-Funktion (ca. Zeile 1283-1295) den `tls:`-Block entfernen:
    ```javascript
    // ENTFERNEN — dieser Block deaktiviert TLS-Zertifikat-Validierung:
    tls: {
        rejectUnauthorized: false
    }
    // Nodemailer's sichere Defaults greifen dann automatisch (rejectUnauthorized: true)
    ```
    Nur diesen Block entfernen. Alle anderen Transporter-Optionen (host, port, auth etc.) bleiben unverändert.

    **Fix B: SQL-Injection-Whitelist für DDL (SEC-02)**

    Direkt VOR der `initializeDatabase()`-Funktion (ca. Zeile 1230) folgende Konstante einfügen:
    ```javascript
    const ALLOWED_TABLES = ['users', 'institutions', 'objekte', 'sessions', 'vorlagen'];
    ```

    Dann an drei Stellen innerhalb von `initializeDatabase()` (Zeilen 1235, 1252, 1255) jeweils VOR dem betroffenen Query einen Guard einfügen:
    ```javascript
    if (!ALLOWED_TABLES.includes(tableName)) {
        throw new Error(`Ungültiger Tabellenname: ${tableName}`);
    }
    ```

    Die betroffenen Queries selbst NICHT ändern — nur den Guard davor einfügen. Die Variable `tableName` muss dabei die Variable sein, die tatsächlich im Query verwendet wird (ggf. nach genauen Variablennamen im Code schauen).

    **Wichtig:** server.js bleibt ein laufender Monolith — keine anderen Änderungen außer diesen zwei Fixes.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App → MySQL | DDL-Queries mit dynamischen Tabellennamen — Injection-Risiko wenn Whitelist fehlt |
| App → SMTP | TLS-Verbindung zur E-Mail — ohne Zertifikat-Validierung ist Man-in-the-Middle möglich |
| Logs → Ops/Attacker | Server-Logs können bei Log-Aggregation oder Log-Leak Credentials exponieren |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Tampering | DDL SHOW TABLES / ALTER TABLE in initializeDatabase() | mitigate | ALLOWED_TABLES-Whitelist vor jedem DDL-Query; throw Error bei ungültigem Namen |
| T-01-05 | Information Disclosure | console.log('Database config', {password}) Zeilen 17-22 | mitigate | Kompletten Log-Block entfernen; Pool-Erstellung ohne Logging |
| T-01-06 | Information Disclosure | Login-Debug-Logs req.body | mitigate | console.log im Login-Endpoint entfernen |
| T-01-07 | Tampering | SMTP-Verbindung ohne TLS-Validierung | mitigate | tls.rejectUnauthorized-Block entfernen — Nodemailer Default (true) greift |
</threat_model>
